 O QUE VAI PARA O VPS (e o que NÃO vai)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  VPS (Oracle Cloud Free Tier — Ubuntu 22.04 ARM)
  ├── docker-compose.yml        ← sobe TUDO isso abaixo
  ├── gateway-rust/             ← compila no Docker durante build
  ├── orchestrator-go/          ← compila no Docker durante build
  ├── mcp-python/               ← roda no Docker com uvicorn
  ├── data/postgres/init.sql    ← executado na 1a subida do Postgres
  └── vps/scripts/              ← scripts de setup e manutenção

  NÃO vai para o VPS:
  └── frontend/                 ← app desktop, roda no PC do usuário
                                   (se conecta ao IP do VPS)

 EXPLICAÇÃO DE CADA ARQUIVO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

docker-compose.yml
  Orquestra todos os containers. Cada serviço tem sua rede interna
  (stack-net). Só as portas listadas ficam expostas externamente.
  Serviços: open-webui, ollama, gateway-rust, orchestrator-go,
            mcp-python, postgres.

gateway-rust/src/main.rs
  Servidor HTTP em Rust usando Axum. Funciona como proxy reverso e
  camada de autenticação. Valida x-api-key em todas as requisições
  antes de repassar ao Go. Porta 8080 externa / 8080 interna.

gateway-rust/Cargo.toml
  Dependências Rust: axum (HTTP), tokio (async), reqwest (proxy),
  tower-http (CORS/trace), serde (JSON).

gateway-rust/Dockerfile
  Build multistage: compila com rust:slim, roda com debian:slim.
  Reduz imagem final de ~900MB para ~30MB.

orchestrator-go/main.go
  Servidor HTTP em Go puro (sem frameworks). Recebe chamadas de
  ferramentas MCP do Open WebUI/gateway, roteia para o Python.
  Expõe: GET /health, GET /tools, POST /call. Porta 9090 interna.

orchestrator-go/go.mod
  Módulo Go simples, sem dependências externas (stdlib only).

orchestrator-go/Dockerfile
  Build multistage: golang:alpine → alpine. Binário estático ~6MB.

mcp-python/main.py
  FastAPI com as ferramentas reais que a IA pode chamar:
    - read_file:   lê arquivo no servidor
    - write_file:  escreve arquivo no servidor
    - run_shell:   executa comando (allowlist de segurança)
    - web_search:  busca DuckDuckGo
    - db_query:    SELECT no Postgres
  Porta 8000 interna, /docs expõe Swagger automático.

mcp-python/requirements.txt
  fastapi, uvicorn, httpx, asyncpg, pydantic

mcp-python/Dockerfile
  Python 3.12-slim com uvicorn --reload (dev) ou sem (prod).

data/postgres/init.sql
  Cria tabelas na 1a inicialização:
    - users:        usuários do sistema
    - chat_history: histórico de conversas com a IA
    - tool_logs:    log de cada tool chamada pelo MCP

vps/scripts/01_install_docker.sh
  Instala Docker + Docker Compose no Ubuntu. Roda UMA vez.

vps/scripts/02_setup_stack.sh
  Clona/copia projeto, configura variáveis de ambiente, sobe a stack.

vps/scripts/03_pull_models.sh
  Baixa modelos no Ollama depois que o container está de pé.
  Escolhe o modelo certo baseado na RAM disponível.

vps/scripts/04_setup_nginx.sh
  Configura Nginx como reverse proxy com HTTPS (Let's Encrypt).
  Expõe só porta 443 externamente.

vps/scripts/05_setup_firewall.sh
  Configura UFW + regras iptables do Oracle Cloud.

vps/scripts/backup.sh
  Faz dump do Postgres e comprime. Pode ser agendado com cron.

vps/scripts/update.sh
  Puxa novas imagens, rebuild, restart zero-downtime.

vps/nginx/neotek.conf
  Config Nginx com SSL, proxy_pass para cada serviço, headers de
  segurança (HSTS, CSP, X-Frame-Options).

vps/systemd/neotek.service
  Systemd unit que sobe o docker-compose no boot automaticamente.

 PASSO A PASSO — SUBIDA INICIAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Provisionar VPS Oracle Free Tier (ARM, Ubuntu 22.04, 4 OCPUs, 24GB)

  2. SSH no VPS:
       ssh ubuntu@SEU_IP

  3. Instalar Docker:
       bash vps/scripts/01_install_docker.sh

  4. Subir a stack:
       bash vps/scripts/02_setup_stack.sh

  5. Baixar modelo de IA:
       bash vps/scripts/03_pull_models.sh

  6. (Opcional) HTTPS:
       bash vps/scripts/04_setup_nginx.sh SEU_DOMINIO

  7. Configurar firewall:
       bash vps/scripts/05_setup_firewall.sh

  8. No app desktop (Neo UI), mude o endereço para o IP do VPS:
       Edite frontend/src/main/main.ts → WEBUI_URL = "http://SEU_IP:3000"
