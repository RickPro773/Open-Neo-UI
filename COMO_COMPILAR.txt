OPEN NEO UI v0.3.3-beta - COMO COMPILAR

ARQUITETURA ATUAL

- Desktop: apps/winui-shell (WinUI 3 + C#)
- API local: services/api-python (Python + FastAPI)
- Backend core: core/native (C++/C)
- Worker opcional: orchestrator-go (Go)
- Infra local: docker-compose.yml

1. COMPILAR O CORE C/C++

Requisitos:
- CMake
- Visual Studio Build Tools ou Visual Studio Community com C++ Desktop

Comando:

  powershell -ExecutionPolicy Bypass -File scripts\build-native.ps1

Saida esperada:

  core\native\build\Release\open_neo_core.dll

2. RODAR A API PYTHON

Requisitos:
- Python 3.12+

Comando:

  powershell -ExecutionPolicy Bypass -File scripts\start-api.ps1

Teste:

  powershell -ExecutionPolicy Bypass -File scripts\health.ps1

3. COMPILAR O DESKTOP WINUI 3

Requisitos:
- Visual Studio com .NET desktop development
- Windows App SDK
- Windows 10/11 SDK

Comandos:

  dotnet build apps\winui-shell\OpenNeo.UI.csproj
  dotnet run --project apps\winui-shell\OpenNeo.UI.csproj

4. RODAR COM DOCKER

Comando:

  docker compose up --build

Servicos:

- api-python: http://localhost:8000
- ollama: http://localhost:11434

5. ICONES

- Windows: assets\icons\logo.ico
- Linux: assets\icons\logo.svg
- macOS: assets\icons\logo.icns

6. COMMIT DA RELEASE

  git add .
  git commit -m "Release v0.3.3-beta native WinUI update"
  git tag v0.3.3-beta
  git push origin main
  git push origin v0.3.3-beta
