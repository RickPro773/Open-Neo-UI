 SETUP NO PC SERVIDOR (Windows)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Instalar Docker Desktop
   https://www.docker.com/products/docker-desktop/
   (durante instalação, habilite WSL 2 se pedido)

2. Instalar e configurar modelos:
   Execute: local-scripts\01_install_ollama.bat

3. Subir a stack:
   Execute: local-scripts\02_start_stack.bat

4. Descobrir o IP para outros PCs:
   Execute: powershell -File local-scripts\get_network_info.ps1

 PORQUE OLLAMA NATIVO (SEM DOCKER)?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Ollama dentro do Docker NÃO consegue usar a GPU com eficiência
  no Windows (Docker Desktop usa WSL 2, que tem overhead de GPU).

  Ollama nativo:
  ✅ Acesso direto à GPU NVIDIA/AMD
  ✅ 2-5x mais rápido para inferência
  ✅ Gerenciamento de modelos mais simples
  ✅ Funciona mesmo se o Docker estiver parado

  O docker-compose usa host.docker.internal:11434 para se comunicar
  com o Ollama nativo rodando no host.

 MODELOS RECOMENDADOS POR HARDWARE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  VRAM NVIDIA   Modelo recomendado      Qualidade
  ──────────── ────────────────────── ──────────
  4 GB          gemma3:4b / qwen3:1.7b   ★★★
  6 GB          qwen3:8b (4bit quant)    ★★★★
  8 GB          qwen3:8b                 ★★★★
  12+ GB        qwen3:14b                ★★★★★
  24+ GB        qwen3:14b + qwen3:8b     ★★★★★

  Sem GPU (CPU only — mais lento):
  RAM 8GB  → gemma3:4b
  RAM 16GB → qwen3:8b
  RAM 32GB → qwen3:14b

 O QUE CADA ARQUIVO FAZ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  docker-compose.yml
    Orquestra 5 containers. Usa host.docker.internal para acessar
    o Ollama nativo. Healthcheck no Postgres garante ordem de subida.

  .env.example → copie para .env e edite as senhas

  local-scripts/01_install_ollama.bat
    Baixa e instala Ollama. Detecta VRAM/RAM e sugere modelo.

  local-scripts/02_start_stack.bat
    Verifica Docker, inicia Ollama, sobe docker-compose, mostra IP.

  local-scripts/03_stop_stack.bat
    Para containers e mata processo Ollama.

  local-scripts/get_network_info.ps1
    Mostra IP local, status de todos os serviços, modelos instalados.

  frontend/
    App desktop Electron. Configure o IP do servidor na aba
    "Configurações" para apontar para o PC que roda a stack.
    Veja COMO_COMPILAR.txt para gerar o .exe.
