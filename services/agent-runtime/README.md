# Open Neo UI Agent Runtime

Camada responsavel pelo loop agentico, permissoes e roteamento de tools.

Versao: `0.3.3-beta`

## Responsabilidades

- decidir quais tools podem ser chamadas;
- emitir eventos para o terminal integrado;
- aplicar politicas de seguranca;
- registrar historico de execucao;
- coordenar modelos locais e remotos.
